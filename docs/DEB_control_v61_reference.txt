Description: 大肥鱼〇V〇 · 桌面宠物、主题换装、触摸互动、AI 对话与语音陪伴。
 【桌面陪伴】在主屏幕与 App 界面显示悬浮桌宠；支持自主活动、角色大小与位置调节、键盘避让；锁屏时根据插件逻辑隐藏或暂停。
 【主题换装】提供配色、服装选择与素材管理入口；支持从下载地址获取素材，或手动导入素材 ZIP。部分新增服装仍需实际资源与运行时兼容性验证。
 【触摸互动】支持单击、双击、长按等动作映射，并提供拖动响应、互动开关与角色行为相关设置。
 【角色动画】包含行走、跑步、跳跃、睡觉、眨眼等动作表现，并提供帧率、自主活动、动作音效等选项；具体动画以安装的素材为准。
 【AI 对话】可配置兼容的 AI 服务端点、模型、提示词、对话历史、记忆与上下文参数；支持按设置启用图像输入和互动唤醒。使用第三方服务可能需要 API Key 与网络连接。
 【对话声音】提供原生音效与豆包语音相关选项，包括音色码、语速、音调与音量调节；语音服务需按实际供应商配置。
 【设备操控】提供屏幕感知、手势、文字输入、应用管理和剪贴板等工具开关。总开关与各工具默认关闭，实际可用范围取决于系统权限、兼容性及运行环境。
 【使用提示】此 DEB 包不包含完整角色素材，需另外下载或导入资源包。当前为 1.2-2~ui1 的商店外观与描述维护版，不包含第五套服装渲染修复。
